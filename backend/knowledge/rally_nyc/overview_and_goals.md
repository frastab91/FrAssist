# Rally NYC: Project Overview & Growth Targets

## Mission & Purpose
Rally NYC is a mobile-first web application designed for New York City tennis players to improve their court experience by providing community-reported crowd levels and wait times while facilitating connections between local players looking for hitting partners.

## Growth Objectives
- **Target User Base**: 1,000 active registered users (`profiles`).
- **Initial Metric**: 29 profiles recorded.
- **Database Schema Notes**:
  - Primary Supabase Project: `oylhowvuhatfiyejjhwd`.
  - Tables: `profiles`, `parks`, `crowd_reports`, `player_posts`, `court_sessions`, `messages`, `push_subscriptions`, `user_preferred_parks`, `user_time_windows`.
  - Important: Use `profiles` table for user profiles and counts (there is no `users_view`).
